# _**Text Formatting**_

*  **Bold**: `**bold**`
*  _Italic_: `_italic_` or `*italic*`
*  **_Bold + Italic_**: `***bold italic***` or `**_bold italic_**`
*  ~~Strikethrough~~: `~~strikethrough~~`
*  `Inline Code`: \`code\`
*  Subscript (H<sub>2</sub>O): `H~2~O` or `H<sub>2</sub>O`
*  Superscript (E = mc<sup>2</sup>)

# _**Paragraphs & Line Breaks**_
* New paragraph: blank lines between the text.
* Hard break: end line with two spaces or `\`

# _**Lists**_
